# Golf Charity Platform 🏌️

A full-stack web application that combines golf scoring, subscription-based rewards, and charitable giving.

## 🌐 Live Demo

[View Live Application](https://golf-charity-platform-beryl-one.vercel.app/)

## ✨ Features

- 🔐 User authentication
- 💳 Subscription-based membership
- ⛳ Golf score submission and management
- 🎁 Monthly draw-based rewards
- ❤️ Charity donations funded through subscriptions
- 📊 User dashboard
- 🗄️ Supabase database integration
- 🚀 Vercel deployment

## 🛠️ Tech Stack

- **Frontend:** Next.js, React, TypeScript
- **Backend:** Next.js
- **Database:** Supabase / PostgreSQL
- **Styling:** CSS
- **Deployment:** Vercel
